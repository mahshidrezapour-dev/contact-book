# Contact Book

A Python program for collecting and organizing contact information using nested dictionaries.

## Features

- Store multiple contacts
- Record each contact's name, phone number, age, and city
- Validate phone number input to ensure it contains digits
- Organize contact details in a nested dictionary
- Display the collected contact records

## Concepts Practiced

- Functions and return values
- Dictionaries and nested data structures
- Loops and conditional statements
- User input and type conversion
- Input validation using string methods

## How to Run

Run `second.py` using Python and enter the requested contact information in the terminal.
